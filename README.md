# niko-videos

Videos editados automáticamente para las cuentas secundarias de TikTok de Niko Calzados.

- `videos/AAAA-MM-DD/`: videos finales publicados ese día (Metricool los toma desde acá).
- `state.json`: material usado, posts programados, control de viralidad a 3 días y tendencias.

No subir videos crudos acá.
